# CDPR compatibility Add-On
This add-on is made for Pleiad and provides an efficient way to restructure mods so they match specific paths. This project could be useful for future implementations such as a more generic restructure function using a config file in order to respect specific paths for specific mods

## How to install
Download this add-on using this command in your terminal:
`curl path/to/release`

- Open Pleiad's extension panel
- Click on "Add an add-on"
- Select the game you want it to be used with such as Cyberpunk or The Witcher 3

## How to use
Just install a mod from Pleiad following the regular procedure. Mods will now follow the recommended pattern for modding as it should.
